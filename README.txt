PORTFÓLIO PURO - HTML + CSS + JAVASCRIPT

Não usa Tailwind, Python, frameworks ou bibliotecas obrigatórias.

Abra index.html no navegador.

PÁGINAS
- index.html
- sobre.html
- especializacoes.html
- projetos.html
- certificados.html
- contato.html

ARQUIVOS PRINCIPAIS
- style.css = toda a aparência e animações CSS
- script.js = modo claro/escuro, cards aparecendo no scroll, navegação ativa e cursor de chama
- assets/ = imagens de referência do ZIP original

ONDE EDITAR
1. Sobre mim: sobre.html, procure [ESCREVA AQUI].
2. Projetos: projetos.html, procure [NOME DO PROJETO] e troque os links SEU-LINK-AQUI.
3. Certificados: certificados.html, procure [NOME DO CURSO], coloque sua imagem e troque SEU-LINK-DO-CERTIFICADO.
4. Contato: contato.html, substitua SEU_USUARIO e SEUEMAIL@email.com.
5. Para colocar imagens próprias, coloque-as em assets/.

TEMA
O tema escolhido fica salvo no navegador. As flores, folhas e contraste acompanham o modo claro/escuro.

CURSOR
Em computadores com mouse, a seta do sistema continua funcionando normalmente e o site cria uma chama branca animada acompanhando o cursor, com faíscas.

FORMULÁRIO
O formulário de contato é visual/demonstrativo. Para receber mensagens de verdade, conecte-o a um serviço de formulários ou a um backend.

Projeto Manual de Boa Conduta integrado em projetos/manual-boa-conduta/index.html.

PROJETO THREE SEAS: abra projetos.html e clique em Conhecer Three Seas; o site completo fica em projetos/three-seas/index.html. Os visuais são recriados em CSS sem marcas d'água premium. Conteúdos demonstrativos devem ser personalizados antes de publicar.
