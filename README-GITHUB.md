# Portfólio | Raissa Silva Andrade

Portfólio pessoal com currículo, formação, certificados e cinco projetos.

## Publicar no GitHub Pages

1. Crie um repositório (ex.: `portfolio-raissa`) ou utilize um já existente.
2. Faça upload **do conteúdo desta pasta na raiz do repositório**; o `index.html` deve aparecer na raiz.
3. Abra **Settings → Pages → Build and deployment**.
4. Marque **Deploy from a branch**, selecione `main` e `/(root)` e salve.
5. Espere a publicação do Pages. O endereço costuma ter o formato `https://raissxx-star.github.io/portfolio-raissa/`, caso esse seja o nome do repositório.

Este pacote inclui PDFs dos certificados, que podem conter nome completo e identificadores. Se não quiser torná-los públicos, remova os PDFs ou use apenas imagens com dados sensíveis ocultos. Verifique também o direito de uso das fotos de artistas incluídas nos projetos.
